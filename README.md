# 〈라파엘〉 시사회 초대장 — 설치 안내

시사회: 2026-11-18(수) 19:40, 롯데시네마 월드타워 (상영관 추후 안내). 회신 = 참석 의사, 동반 2인까지.

## 구성
- `index.html` — 초대장 페이지 (모바일 우선, 단일 파일)
- `assets/` — 포스터 이미지 (세로/가로, JPG + WebP)
- `apps-script/Code.gs` — Google Apps Script 서버 (명단 대조 + 회신 기록)

## 회신 흐름
1. 성함, 전화번호(숫자만), 이메일 입력 → 동행자(선택, 최대 2명, 성함·연락처만) → 동의 → 회신하기
2. 서버(Apps Script)가 받은 내용을 "시사회 회신" 시트에 그대로 기록 (명단 대조 없음)
3. 같은 연락처로 다시 보내면 기존 줄을 덮어씀 (완료 화면의 "회신 내용 수정")
4. 잘못 들어온 데이터는 시트에서 수기로 거름

## 설치 (약 10분)
1. `마테오_시사회 초대 명단.xlsx` 를 Google Drive 에 올리고 열어서 **파일 > Google Sheets로 저장**.
2. 그 스프레드시트에서 **확장 프로그램 > Apps Script** 를 열고, `Code.gs` 내용 전체를 붙여넣고 저장.
3. **배포 > 새 배포** → 유형 "웹 앱" → 실행 사용자 "나" → 액세스 권한 "모든 사용자" → 배포. 처음 한 번 권한 승인.
4. 발급된 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 `index.html` 의 `const ENDPOINT = ''` 안에 붙여넣기.
5. 브라우저에서 페이지를 열어 명단에 있는 번호로 한 번 회신해 보면 "시사회 회신" 시트가 자동 생성되고 한 줄이 기록됨.

## 데모 모드
`ENDPOINT` 가 비어 있으면 전송하지 않고 완료 화면만 보여줌. 실제 배포 전 반드시 URL을 채울 것.
